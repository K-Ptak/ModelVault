# Changelog

All notable changes to ModelVault are listed here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [semantic versioning](https://semver.org/).

## [Unreleased]

### Added
- Batches: many pieces on one plate, with summed filament, time and cost, a bed capacity check, a one-click split and a 3D layout preview.
- Builds for Linux (AppImage, .deb) and macOS (Apple Silicon and Intel) next to Windows.
- Contributing guide, issue and pull request templates, branch strategy.

### Changed
- On Linux and macOS, file-manager and trash wording follows the system (Finder, Trash…).
- Update check on macOS, `.deb` and portable versions: ModelVault tells you about a new version and opens the download page.

## [1.0.0] – unreleased

First version: model library, 3D preview, multicolour files, pricing, orders, clients, filament stock, print queue,
calendar and notifications, printer library with build volume and AMS, PDF quotes, backups, PL/EN/DE.
